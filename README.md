# Project M

턴제 탑다운 그리드 로그라이크. 7개 속성 마법과 희귀한 시간 마법이 **상태 × 속성 규칙**으로 연결되는 전투가 핵심이다.
Unity 6.6 · URP 2D · Input System · 1인 개발.

## 빠른 시작

1. Unity 6.6 (6000.6.0f1)로 연다.
2. `Assets/_Project/Scenes/Main.unity`를 열고 플레이한다.
3. 테스트: `Window > General > Test Runner > EditMode` → 전체 실행.
4. 씬 참조가 깨졌으면 메뉴 `ProjectM/Setup/Main Scene`.

새 PC에서 이어갈 때는 [TASKS.md](TASKS.md)의 "다른 PC에서 할 일"을 따른다.
