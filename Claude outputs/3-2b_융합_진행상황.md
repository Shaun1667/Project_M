## 6. 점검하며 본 작은 주의점

- **`FusionCatalogAsset.Entry.StatusChancePercent` 기본값이 0이다.** 직렬화 구조체라 인스펙터에서 새 줄을 추가하면 0으로 시작한다. 지금 3종은 상태가 없어서 영향이 없지만, 나중에 상태를 거는 융합을 넣고 확률을 비워 두면 조용히 안 걸린다. Setup 메뉴에서 넣을 때 100을 명시하거나, `AppliesStatus != None && 확률 0`이면 경고하는 검사를 두면 안전하다.
- **불 + 번개 결과의 속성은 번개다** (모양을 정한 Beam 주문의 속성을 따름). 반응을 일으키지 않으므로 지금은 영향이 없지만, 나중에 속성 저항 · 약점이 생기면 "융합 주문의 속성"을 따로 정해야 한다.
- **불 + 물 → 화염 지대**는 REACTIONS 5번에 결정으로 적혀 있어 의도된 설계다. (이전 정리에서 v0.3의 "증기"와 다르다고 적었던 것은 철회.)
