속성과 상태가 맞물리는 턴제 마법 로그라이크
A turn-based pixel roguelike where elemental spells chain into reactions.

🔥 어떤 게임인가요?

무작위로 생성되는 던전을 한 칸씩 내려가며, 마나로 주문을 쓰는 마법사가 됩니다.
주문은 상대를 젖게 · 얼게 · 불타게 · 중독되게 만들고, 다른 속성과 만나면 반응이 일어납니다.

  • 💧 젖은 적에게 ⚡ 번개 → 감전, 젖은 적들 사이로 사슬처럼 번짐
  • 💧 젖은 적에게 ❄ 얼음 → 빙결, 얼어붙은 적에게 ⚡ 번개 → 파쇄
  • ☠ 중독된 적에게 🔥 불 → 독화, 독구름에 번개 → 가스 폭발
  • 🔮 마법 융합기로 주문 두 개를 합쳐 용암 분출 · 빙결 파도 · 폭발 마법

⚔ 특징

  • 턴제 · 8방향 그리드 이동, 그림자 투사 시야
  • 마법서로 배우는 5속성 주문 (불 · 얼음 · 번개 · 독 · 물) + 반응 10여 종
  • 무기 6종 · 갑옷 5종 · 힘과 강화, 물약 · 주문서 식별 시스템
  • 5층 던전과 보스 — 슬라임 소녀
  • 64px 픽셀 그래픽

🎮 조작

이동 · 공격방향키 / WASD / 넘패드 (대각선 = 두 키 함께), 마우스 클릭
주문 · 아이템숫자 1~6 → 조준 (Tab 다음 대상) → Space / Enter / 클릭
