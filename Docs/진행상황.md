## 5. 작업 규칙 요약 (CLAUDE.md)

- 한국어 · 1인 개발 · 한 번에 한 항목 · 요청 안 한 시스템 미리 만들지 않기.
- 설계 결정은 선택지 + 추천안 → `결정 (YYYY-MM-DD): … — 이유`로 TASKS에.
- 작업 브랜치에 `MM.DD/Phase-항목/PascalCase요약` 커밋, 병합은 지시가 있을 때 fast-forward, 푸시는 사용자가.
- 테스트는 작성하되 실행은 사용자가 (보고에 "테스트 작성, 실행 안 함").
- Simulation은 Unity를 모름 · 화면은 이벤트로만 · 수치는 데이터 에셋 + BALANCE.md + 검산 테스트.
- Setup 메뉴 뒤 `Galmuri11 SDF.asset` 되돌리기 · 에셋 이동/삭제는 `git mv`/`git rm`.
