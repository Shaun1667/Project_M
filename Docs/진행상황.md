## 1. 다른 PC에서 이어 가기

1. `git fetch` → `git checkout phaseP-2d` (처음이면 `git checkout -b phaseP-2d origin/phaseP-2d`).
2. Unity 6.6으로 열기 → 패키지 `com.unity.2d.tilemap.extras` 9.0.0이 manifest에 있다(RuleTile용, 자동 설치).
3. `Assets/_Project/Scenes/Main.unity` → 콘솔 오류 0 확인 → 메뉴 `ProjectM/Setup/Main Scene` 한 번(멱등 — 벽 RuleTile 규칙 · 안개 · 유닛 그림 연결을 다시 만든다).
   실행 뒤 `git checkout -- "Assets/_Project/Art/Fonts/Galmuri11 SDF.asset"`.
4. 플레이 → 캐릭터 선택(금발 / 흑발) → 2D 픽셀 화면.
5. Claude Code: Unity MCP 등록(CLAUDE.md "새 PC 환경 준비"). Varco 이미지 생성은 브라우저에서 Varco 플로우를 열어 두어야 쓸 수 있다(GPT 2.5 = `gpt-image-2.5-flare`).

## 4. 주의 (이번에 겪은 것)

- Unity MCP가 플레이 모드 종료 · 스크립트 컴파일 중에 RunCommand가 계속 시간 초과될 때가 있다 → 콘솔 읽기는 되면 Unity 창을 한 번 클릭하거나, 사용자가 Setup 메뉴를 직접 실행.
- Bash heredoc에 `'''`나 역슬래시가 있으면 깨진다 → 파이썬 수정 스크립트는 Write로 파일을 만든 뒤 실행.
- 참고 스크린샷(SPD 등)은 Varco에 올리지 않는다 — 분위기만 글로 설명.
- 작업 트리에 늘 남는 변경(Rune 재질 · URP 설정 · ProjectSettings · `_Recovery/` · PDF)은 이번 작업과 관계없어 커밋하지 않았다.
