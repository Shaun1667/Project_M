## 1. 다른 PC에서 이어 가기

1. (이 PC) `git push` — 푸시 전이면 다른 PC에 10-26 작업이 없다.
2. `git fetch` → `git checkout phaseP-2d` (처음이면 `git checkout -b phaseP-2d origin/phaseP-2d`).
3. Unity 6.6으로 열기 → 패키지 `com.unity.2d.tilemap.extras` 9.0.0(RuleTile용, 자동 설치).

   실행 뒤 `git checkout -- "Assets/_Project/Art/Fonts/Galmuri11 SDF.asset"`.

## 3. 남은 것 · 열린 질문

- **이펙트 확인 못 한 것:** 크기를 키운 뒤(투사체 1.2칸 · 맞음 · 반응 1.5칸)의 모습, 3×3 폭발 · 융합은 렌더로 못 봤다(Unity MCP가 플레이 모드에서 응답 없음). 직접 플레이로 확인 필요.
- **이펙트 남은 것:** 지형 칸에 예전 색 오버레이가 그림 뒤에 네모로 함께 보임(어색하면 2D에서 끄기) · 바닥 아이템 반짝임(그림 `item_sparkle`은 있음, 미연결) · 빙판 그림 없음.
- **사용자에게 물어볼 것(답 대기):** 한 칸 기둥도 한 줄 벽처럼 칸 안에만 그릴지(지금은 윗면이 위 칸으로 솟음).
- **Phase P 남은 단계:** ⓑ 나머지 — 적 · 보스 걷기 / 공격 모션, 흑발 캐릭터 걷기 · 계단 그림(예전 바닥 무늬) · 문 타일 · ⓔ 3D 정리(3D 표현 코드 · Varco 모델 · `Pixel2D` 상수 제거).
- 확인 못 한 것(전부터): 직접 플레이(걷기 · 방향 · 피격 · 사망 연출 · 5층 보스 · 인벤토리 · 빠른 칸 아이콘).
- 그 밖(Phase P 전부터): 3-10b 인벤토리 UI(SPD 배치 · F 키) · 남은 SPD 물약 · 주문서 효과 · 테스트 실행(사용자) · main 병합.

## 4. 주의 (이번에 겪은 것)

- Unity MCP가 플레이 모드 · 컴파일 중에 RunCommand가 계속 시간 초과될 때가 있다 → 창 제목에 busy · Compiling이 없어질 때까지 기다리고, 플레이 모드에서 멈추면 사용자가 에디터에서 플레이를 끈다.
- 플레이 모드 확인은 RunCommand에서 `GameRoot.SendMessage("StartNewRun", 모습 ID)` → `World.Events.Publish(…)` + `Flush` → `FxPresenter.Advance` → 카메라 `Render`로 PNG를 찍었다.
- Bash heredoc에 `'''`나 역슬래시가 있으면 깨진다 → 파이썬 수정 스크립트는 Write로 파일을 만든 뒤 실행.
- 참고 스크린샷(SPD 등)은 Varco에 올리지 않는다 — 분위기만 글로 설명.
- Varco에는 다른 프로젝트 플로우(조선 스팀펑크 등)도 열려 있을 수 있다 → `list_flow_sessions`에서 f679a6c8을 골라 쓴다.
- itch.io 파일 올리기: 숨은 file input은 `HTMLInputElement.prototype.click`을 잠시 바꿔 잡아 보이게 한 뒤 `file_upload`. "Upload" 글자로 버튼을 찾으면 상단 "Upload new project"가 먼저 걸리니 id(`image-uploader-0/1`)로 찾는다.
- 작업 트리에 늘 남는 변경(Rune 재질 · URP 설정 · ProjectSettings · `_Recovery/` · `.claude/` · 개발정리 PDF)은 작업과 관계없어 커밋하지 않았다.
