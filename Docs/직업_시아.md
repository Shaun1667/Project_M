## 4. 너클 강화 [제안]

- 시아 기술(도약 포함 6개)을 너클(`knuckle`)을 들고 쓰면 **피해 × 1.5 (내림) · 사거리 + 1** — 루멘 + 창과 같은 값 · 같은 규칙(`SpellModifiers`). 도약은 사거리만.
- 너클 자체의 두 번 치기는 누가 들어도 같다 (루멘도 들 수 있음 — 강화는 없음).
