# 무기 에셋 목록 — 근접 무기 6종

> 작성 2026-10-19. 무기 데이터는 `Docs/장비_데이터.md`. 공통 규격 · 연결 방식은 `Docs/ART_ASSETS.md`(0-1 규격, 12번 Varco 모델)와 같다.
> 무기가 화면에 나오는 곳은 셋이다: **① 바닥에 떨어진 모습**(마법서처럼 맵에 배치) **② 들고 있는 모습**(플레이어 손) **③ UI 아이콘**(인벤토리 · 빠른 칸 · 장비 칸 · 결과 화면).
> 3D 모델 하나로 ①과 ②를 함께 쓰고, ③은 그 모델을 렌더해서 만든다. 모델 한 개 = 무기 한 종.
> 우선순위: **1차** = 장비 시스템을 플레이하는 데 필요 / **2차** = 손맛 / **3차** = 다듬기.

## 1. 무기 모델 (Varco 3D) — 6개, 1차

| ID | 이름 | 파일 이름 (안) | 길이 (게임 안, m) | 생김새 | 쥐는 곳 |
|---|---|---|---|---|---|
| `shortsword` | 소검 | `Prop_Weapon_Shortsword` | **0.45** | 곧은 양날 짧은 칼, 작은 십자 손잡이 — 기준 무기라 가장 평범하게 | 손잡이 가운데 |
| `hand_axe` | 손도끼 | `Prop_Weapon_HandAxe` | **0.35** | 짧은 나무 자루 + 한쪽 날 도끼머리 — 가볍고 잘 맞는 느낌 | 자루 아래 1/3 |
| `spear` | 창 | `Prop_Weapon_Spear` | **1.10** | 긴 나무 자루 + 좁은 잎 모양 창날 — 2칸 공격이 한눈에 보이게 **가장 길게** | 자루 아래 1/3 |
| `quarterstaff` | 육척봉 | `Prop_Weapon_Quarterstaff` | **1.00** | 날 없는 곧은 나무 봉, 양 끝에 금속 고리 — 방어용 느낌. **마법 지팡이(`Prop_MageStaff`)와 확실히 다르게** (보석 · 장식 없음) | 가운데 (양손) |
| `dirk` | 더크 | `Prop_Weapon_Dirk` | **0.25** | 가늘고 뾰족한 단검, 손잡이에 보호대 거의 없음 — 기습용 | 손잡이 |
| `sickle` | 손낫 | `Prop_Weapon_Sickle` | **0.30** | 짧은 손잡이 + 반달 모양 휜 날 — 무겁고 거친 느낌(정확도 낮음) | 손잡이 |

길이는 플레이어(양 마법사, 키 0.99 m)와 지팡이(0.85 m)에 맞춘 값이다. Varco는 모든 모델을 가장 긴 쪽 1 m로 내보내므로 크기는 프리팹 배율로 맞춘다 (ART_ASSETS 12번과 같은 방식).

### 1-1. 모델 규격 (ART_ASSETS 0-1 소품 기준)

| 항목 | 값 |
|---|---|
| 삼각형 | **≤ 1,500** (소품) — 지팡이 1,586과 비슷하게 |
| 텍스처 | 모델당 1장 512², 베이스컬러 (+ 노멀). 이름 `<파일 이름>_base_color` · `_normal`, 재질 `<파일 이름>_Mat` |
| 원점 | **쥐는 곳**에 두면 손에 붙이기 쉽다. 안 되면 아무 곳이나 — 프리팹에서 "길이 몇 % 지점을 쥠"으로 맞춤 (지팡이와 같음) |
| 방향 | 날 · 끝 = **+Y**(위로 세운 모습)로 통일하면 보정 표가 단순해진다 |
| 화풍 | 스타일라이즈드 · 굵은 형태 · 단순한 색 (양 마법사 · 적과 같은 톤). 금속은 채도 낮게 — 속성 색 이펙트가 잘 보이게 |
| 형식 | FBX, 조명 · 카메라 없이 (SheepMage에 점광원이 섞였던 문제) |
| 넣을 곳 | `Assets/_Project/Art/Varco3D/` (다른 Varco 원본과 같이) |

## 3. 바닥에 떨어진 모습 — 추가 에셋 없음 (1차)

- 1번 모델을 바닥 칸 위에 눕히거나 떠서 천천히 돌게 한다 — 마법서(3-5 `FloorItemPresenter`)와 같은 방식.
- 반짝임은 지금 있는 팩 효과를 쓴다 (`FxCatalog` `item.<무기 ID>` 한 줄, 색은 금속 회색 계열). **새 이펙트 에셋 필요 없음.**
- 모델이 오기 전에는 그레이박스 도형(길쭉한 상자)으로 그린다.

## 4. 들고 있는 모습 — 추가 에셋 없음, 결정 필요 (2차)

- 1번 모델을 플레이어 손 뼈에 붙인다 (지팡이 `Prop_MageStaff`를 붙인 방식 그대로 — `VarcoModelSetup.AttachStaff`).
- **결정 (2026-10-19, 사용자): (가)** — 무기를 들면 오른손 = 무기, 지팡이는 숨김. 무기가 없으면 지금처럼 지팡이.
  - (가) 오른손 = 무기, 지팡이는 숨김 — 단순, 주문 시전 때 지팡이 끝 빛(`cast.*`)이 무기 끝에서 나옴 ← **선택**
  - (나) 오른손 = 무기, 왼손 = 지팡이 — 마법사 느낌 유지, 왼손 쥐는 자세 조정 필요
  - (다) 들고 있는 모습은 그리지 않음 — 바닥 · 아이콘만 (가장 적은 작업)
- 창 · 육척봉(1 m 넘음)은 Idle · Walk에서 몸 · 땅과 겹치는지 시간대별 렌더로 확인해야 한다.

## 5. 공격 애니메이션 — Mixamo 클립, 2~3차

지금 근접 공격은 코드 찌르기(0.3 m 앞으로)뿐이다 (G-2b). 무기 종류에 맞는 클립이 있으면 같은 이벤트 지점(`UnitDamagedEvent` · `AttackMissedEvent`)에서 재생한다 (ART_ASSETS 12-1과 같은 Humanoid 리타깃).

| 클립 (안) | 쓰는 무기 | Mixamo 검색어 예 | 우선 |
|---|---|---|---|
| `Attack_Slash` (한 손 내려베기) | 소검 · 손도끼 · 손낫 | `Sword And Shield Slash`, `Standing Melee Attack Downward` | 2차 |
| `Attack_Stab` (찌르기) | 창 · 더크 | `Stabbing`, `Spear Thrust` | 2차 |
| `Attack_Staff` (봉 휘두르기) | 육척봉 | `Standing Melee Attack Horizontal` | 3차 |
| `Attack_Unarmed` (맨손) | 무기 없음 | `Punching` | 3차 |

- 클립은 한 번 재생에 **0.4초 안**이어야 한다 (CLAUDE.md 연출 규칙) — 길면 재생 속도를 올린다.
- 앞뒤 이동(XZ)은 굽지 않고 버림 (G-2c 걷기 문제와 같은 이유).

## 8. Varco에서 만든 모델 확인 (2026-10-19)

Varco 플로우 "Untitled"(`f679a6c8…`)의 TextInput → GenerateImage(nano-banana-pro, 3:4) → Generate3D(삼각형 1,500 · tri · 텍스처 1024 · PBR 없음) 6줄, 모두 성공.

**프로젝트에 가져옴 (2026-10-19, 사용자: "지금 나와 있는 모델대로")** — 아직 게임에 연결하지 않음 (프리팹 · 손 · 바닥 표시는 장비 시스템 때):
- FBX `Art/Varco3D/Prop_Weapon_{Shortsword, HandAxe, Spear, Quarterstaff, Dirk, Sickle}.fbx` (조명 · 카메라 가져오기 끔)
- 텍스처 `Textures/<이름>_base_color.png` · `_normal.png` — 같은 생성 결과의 GLB에서 꺼냄 (FBX에 묻힌 텍스처는 이름이 모두 같아서), 가져오기 최대 512² · 노멀은 Normal map
- 재질 `Materials/<이름>_Mat.mat` (URP Lit, 매끈함 0.2 · 금속 0 · 인스턴싱 — 지팡이와 같은 값), FBX `material_0`에 다시 연결
- ~~Unity에서 놓으면 +X로 누운 채 나온다~~ — 고침 (2026-10-19, 3-7a): 렌더할 때 FBX 루트의 축 회전(270, 0, 0)을 덮어써서 생긴 착시. 루트 회전을 두면 **날이 +Y(위)로 서고 원점은 가운데** (지팡이는 원점이 아래 끝)
- **연결 (3-7a)**: 바닥 = `Prefabs/Varco/Weapon_<이름>`(세운 모습, 길이 = 1번 표) → `Data/Visuals/ItemVisualCatalog.asset`, `FloorItemPresenter`가 눕혀 떠 돌게. 손 = 플레이어 프리팹 오른손 뼈 아래 `Weapon_<아이템 ID>` 6개(꺼 둠, 들면 켜고 지팡이 숨김). 쥐는 곳 · 기울기는 `VarcoModelSetup.WeaponSpecs`: 소검 0.12 · 손도끼 0.25 · 창 0.35 · 육척봉 0.45 · 더크 0.15 · 손낫 0.15(길이 비율), 한 손 무기 4종은 앞으로 70°(세우면 몸에 가려 위에서 안 보임), 창 · 육척봉은 세움. 더크는 0.25 m라 위에서 잘 안 보임 — 플레이 확인 때 길이 조정 후보
GLB를 받아 삼각형 · 크기를 재고 정면 · 측면을 간이 렌더해 봤다 (삼각형마다 한 색 — 텍스처 세부는 이 렌더로 판단 못 함).

| 무기 | Generate3D 노드 | 삼각형 | 내보낸 크기 (가로 × 높이 × 깊이 m) | 컨셉과 비교 |
|---|---|---|---|---|
| 소검 | `abbd9672` | 1,500 | 0.14 × 0.98 × 0.36 | 형태 일치. 측면에서 칼끝이 살짝 갈라져 보임 (확인 필요) |
| 손도끼 | `99f83b0d` | 1,546 | 0.13 × 1.00 × 0.44 | 일치 |
| 창 | `2c0da411` | 1,624 | 0.09 × 1.00 × 0.04 | 처음 것은 창날 가운데가 뚫린 고리 모양 → 다시 만듦 (Claude 1회: 꽉 찼지만 끝이 둥근 삽 모양 → **사용자가 다시 생성한 것으로 확정**, 2026-10-19). 꽉 찬 뾰족한 잎 모양 |
| 육척봉 | `2f03c2eb` | 1,766 | 0.11 × 1.00 × 0.11 | 일치 (지팡이와 구별됨) |
| 더크 | `316772d0` | 1,500 | 0.23 × 0.99 × 0.11 | 일치 |
| 손낫 | `b169545b` | 1,500 | 0.14 × 1.00 × 0.56 | 일치 |

- 공통: 높이 1 m로 정규화 · **날이 +Y(위)** · 원점은 **가운데**(아래 끝 y = −0.5) — 쥐는 곳 맞춤은 프리팹에서 (지팡이처럼 "길이 몇 % 지점을 쥠").
- 삼각형은 규격(≤ 1,500)을 3개가 조금 넘음(최대 1,766) — 소품으로는 문제없는 수준.
- 텍스처 1024² — 규격은 512². 가져올 때 Max Size 512로 줄이면 된다.
- 받을 때: `get_output_downloads`(fbx)로 FBX를 받아 `Art/Varco3D/`에, 이름은 1번 표 파일 이름으로 (묻힌 텍스처 이름이 모두 같으므로 꺼낼 때 이름을 바꾼다 — CLAUDE.md 아트 규칙).
