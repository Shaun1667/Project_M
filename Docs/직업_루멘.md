## 4. 특성 — SPD식 단계 (C5) [제안 — 목록 · 수치 확인 필요]

점수: 레벨업마다 1점. 1단계 = 레벨 2~6에 얻는 5점(공통 4개, 각 최대 2점), 2단계 = 레벨 7~12에 얻는 6점(형태별 4개, 각 최대 3점). 2단계는 형태를 고른 뒤에만 찍을 수 있고, 그 전에 얻은 2단계 점수는 모아 둔다.

| 단계 | 특성 (안) | 1점 / 2점 / 3점 |
|---|---|---|
| 1 공통 | 빛의 숙련 | 빛의 창 기술 피해 +1 / +2 |
| | 마나 순환 | 빛의 창 기술로 적을 쓰러뜨리면 마나 +1 / +2 |
| | 창 다루기 | 창(`spear`)을 들면 명중 +2 / +4 |
| | 빛의 가호 | 최대 체력 +3 / +6 |
| 2 근접형 | 끝없는 찌르기 | 연속 찌르기 횟수 +1 / +2 / +3 |
| | 긴 창날 | 관통 찌르기 길이 +1 / +2 / +3 |
| | 질주 | 돌진 거리 +1 / +2, 3점이면 돌진에 맞은 적 둔화 |
| | 창의 기세 | 근접 공격(일반 · 빛의 창)이 맞으면 마나 +1 확률 20 / 40 / 60% |
| 2 원거리형 | 빛의 비 | 다중 발사 대상 +1 / +2 / +3 |
| | 꿰뚫는 빛 | 관통 발사 피해 +1 / +2 / +3 |
| | 가벼운 손 | 빛의 창 던지기 마나 2 → 1 (1점), 사거리 +1 / +2 (2 · 3점) |
| | 그림자 사냥 | 자신을 못 본 적에게 빛의 창 기술 피해 ×1.25 / ×1.5 / ×1.75 (기습과 같은 판정) |

- 특성 효과는 `SpellModifiers` 같은 **한 조회 지점**에서 읽어 시뮬레이션 · 미리보기 · 연출이 같은 값을 쓴다 (CLAUDE.md 코딩 규칙).
- 레벨 13 이후 점수 · 3단계는 [미정].
